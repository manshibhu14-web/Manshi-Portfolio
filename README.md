# Manshi Gupta Portfolio

Light-theme React portfolio starter.

## Run locally
1. Install Node.js.
2. Extract this folder.
3. Run `npm install`
4. Run `npm run dev`

## Personalize before publishing
- Replace `your-email@example.com` in `src/App.jsx` with your real email.
- Replace LinkedIn and GitHub placeholder URLs with your profile URLs.
- Add real project screenshots, GitHub repositories, and live demo links.
- Verify your experience dates and project feature details before publishing.
- Add your resume PDF and link it from the hero/navigation if desired.

The project visuals are CSS mockups, not screenshots of your deployed projects.
